# Dossier Images

Placez vos images ici pour le site JETC Solution.

## Photo Hero

- **Fichier** : `johnny-hero.jpg`
- **Format recommandé** : Portrait (ratio 4:5)
- **Dimensions minimales** : 800x1000px
- **Utilisation** : Photo du Hero (visible au hover)

## Photo Signature

- **Fichier** : `photo-profile.jpg`
- **Format recommandé** : Carré ou portrait
- **Utilisation** : Section Signature

## Logo

- **Fichier** : `logo-jetc.png`
- **Format recommandé** : PNG avec transparence
- **Utilisation** : Section Signature

---

Une fois vos images ajoutées, décommentez les lignes correspondantes dans les composants concernés.
